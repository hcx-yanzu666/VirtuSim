# 运行一次导航

日常运行只需要准备 Ubuntu 上的 Nav2 参数、地图和 Bridge，然后启动 Nav2、Bridge 和 UE。

## 1. 替换 Ubuntu 文件

将 Windows 仓库中的 `Tools/ROS2/deploy/` 复制到 VMware 共享目录，例如：

```text
/mnt/hgfs/ShareVmware/deploy
```

在 Ubuntu 执行：

```bash
source /opt/ros/humble/setup.bash
export ROS_DOMAIN_ID=0
unset ROS_LOCALHOST_ONLY

SHARE=/mnt/hgfs/ShareVmware/deploy
TARGET=/home/ros2/virtusim_nav2

mkdir -p "$TARGET/params" "$TARGET/maps" "$TARGET/scripts"
cp "$SHARE/nav2_params_full.yaml" "$TARGET/params/"
cp "$SHARE/warehouse_map.yaml" "$SHARE/warehouse_map.pgm" "$TARGET/maps/"
cp "$SHARE/goal_bridge.py" "$TARGET/scripts/"
python3 -m py_compile "$TARGET/scripts/goal_bridge.py"
```

正常运行只需要以下文件：

```text
/home/ros2/virtusim_nav2/params/nav2_params_full.yaml
/home/ros2/virtusim_nav2/maps/warehouse_map.yaml
/home/ros2/virtusim_nav2/maps/warehouse_map.pgm
/home/ros2/virtusim_nav2/scripts/goal_bridge.py
```

## 2. 启动 Nav2

在 Ubuntu 终端执行：

```bash
source /opt/ros/humble/setup.bash
export ROS_DOMAIN_ID=0
unset ROS_LOCALHOST_ONLY

ros2 launch nav2_bringup bringup_launch.py \
  map:=/home/ros2/virtusim_nav2/maps/warehouse_map.yaml \
  params_file:=/home/ros2/virtusim_nav2/params/nav2_params_full.yaml \
  use_sim_time:=true
```

保持该终端运行。

## 3. 启动 Bridge

新开 Ubuntu 终端执行：

```bash
source /opt/ros/humble/setup.bash
export ROS_DOMAIN_ID=0
unset ROS_LOCALHOST_ONLY

python3 /home/ros2/virtusim_nav2/scripts/goal_bridge.py
```

只启动一个 `goal_bridge.py`。

## 4. 启动 UE

打开 `VirtuSim.uproject`，进入当前导航关卡并点击 Play。确保 UE 与 Ubuntu 使用相同的 ROS Domain，并且场景中的地图、机器人和碰撞体与部署的 `warehouse_map` 一致。

之后从 UE 发送导航目标即可。正常链路为：

```text
UE 目标 → /virtusim/goal_pose → goal_bridge → Nav2
Nav2 /cmd_vel → UE 机器人
Nav2 状态 → goal_bridge → UE
```

## 5. 停止

依次在 Nav2、Bridge 终端按 `Ctrl+C`，再停止 UE。重新运行时按相同顺序启动 Nav2、Bridge、UE。

如果更换了 UE 场景或碰撞体，先在 UE 中使用 `NavigationMapExporter` 重新导出 PGM/YAML，再替换 Ubuntu 的地图文件。
